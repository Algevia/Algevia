Algebraic Expressions

Step 1 — Understand

Algebra uses letters to represent numbers. An algebraic expression can contain numbers, letters and mathematical operations.

For example:

3x + 5x = 8x

The terms contain the same variable, x, so we can add their coefficients:

3 + 5 = 8

The key idea is: only like terms can be collected together.

For example:

4x + 3x = 7x

but

4x + 3y cannot be simplified to 7xy.

Step 2 — Worked Example

Simplify:

7x + 3 + 2x + 5

First collect the x terms:

7x + 2x = 9x

Then collect the numbers:

3 + 5 = 8

Therefore:

9x + 8

Notice that we kept the x terms and number terms separate.
